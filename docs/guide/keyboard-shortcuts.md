Shortcuts work on the web app on a computer. Most are ignored while you are
typing in a text field, so fields keep their own editing keys.

| Keys | What it does |
|---|---|
| **/** or **Ctrl+F** (**Cmd+F** on Mac) | Focus the search box (replaces the browser's find) |
| **↑ ↓** in the search results, **Enter**, **Esc** | Move, open the highlighted result, clear the search |
| **Ctrl+Z** (**Cmd+Z**) | Undo the last route change |
| **Ctrl+Shift+Z** or **Ctrl+Y** (**Cmd** on Mac) | Redo |
| **Esc** | Close one thing at a time: the open feature card, the leg editor, the map info panel, the map tools menu, or cancel a waypoint drag or route extension |

Escape never closes a card while you are typing in a field: it first
cancels that field.

## Simulator

With **Go flying** set to the simulator (see
[Simulators and devices](./simulators-and-devices.md)):

| Keys | What it does |
|---|---|
| **←** / **→** | Turn left / right |
| **↑** / **↓** | Increase / decrease speed |
| **+** / **−** | Climb / descend |
| **Q** | Jump 1 NM ahead along your heading |

## Aircraft menu

In the aircraft chip's menu: **↑ ↓** move, **Home** and **End** jump to the
first and last, **Esc** closes it.
