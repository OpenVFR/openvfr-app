OpenVFR is built on open data. The full, current list with licences is on
the [credits page](https://openvfr.org/credits), and the app's map
information dialog shows the same list.

In short: weather from NOAA Aviation Weather Center, model wind from
Open-Meteo, terrain from EU-DEM via OpenTopoData, and aviation and map data
from open sources such as OpenAIP and OpenStreetMap.

Data can be out of date or incomplete. Check official sources before every
flight.
